# CivilDraft AI

Original, AI-assisted civil engineering drafting skill for AutoCAD and Civil 3D. Designed for beginner-to-professional learning and drafting workflows across civil engineering disciplines.

The complete v0.1.0 starter package is provided in the release archive: `releases/civildraft-ai-v0.1.0.zip` (to be added).

## Scope
- AutoCAD drafting fundamentals and workflows
- Civil 3D workflow guidance
- Architectural, structural, roads, surveying, drainage and infrastructure drafting references
- Quality-control checklists and starter AutoLISP utilities
- Portable guidance for Claude, ChatGPT, Gemini and other assistants

## Important limitations
This project assists with drafting and learning; it does not replace engineering judgment, design verification, code review, or approval by a qualified professional. Verify all dimensions, units, standards, software-version behavior and project requirements. Starter AutoLISP routines have not yet been validated across AutoCAD releases.

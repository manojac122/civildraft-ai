# Search discovery and Google indexing

CivilDraft AI is a technical learning resource. Search visibility should come from useful, original, maintained documentation—not keyword stuffing, automated thin pages, paid backlinks, or ranking promises.

## Publish the documentation site

1. Push the complete repository to GitHub.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/docs`, then save.
3. Confirm the live URL is `https://manojac122.github.io/civildraft-ai/`. If GitHub assigns a different URL, update the canonical URL, Open Graph URL and sitemap to match.
4. Open the site in a private browser window and confirm the page, links, robots.txt and sitemap load without authentication.
5. Add the verified site property in Google Search Console, complete ownership verification, submit the sitemap URL and inspect the homepage.
6. Monitor indexing and search queries. A sitemap is a discovery hint, not a guarantee of indexing or ranking.

## Useful original article topics

- AutoCAD layers for civil engineering drawings: naming, properties and safe setup.
- Model space vs paper space for civil engineering drawing sheets.
- AutoCAD plotting checklist: page setup, CTB/STB, lineweights and PDF review.
- AutoLISP safety: loading, inspecting and testing routines on drawing copies.
- Civil 3D surface and alignment workflow overview, with software-version caveats.
- Survey drawing QA/QC: coordinates, datums, units, control points and source traceability.
- Road plan-profile-cross-section drawing coordination.
- Drainage plan and long-section drafting checklist.
- Geotechnical borehole log and soil-profile drawing documentation.

Each guide should solve one real user problem, show prerequisites and expected outputs, identify software/version assumptions, cite official documentation where relevant, and state what was actually tested. Do not publish thin pages that merely repeat the README.

## Ethical discovery

- Use descriptive page titles, headings, URLs and link text.
- Link related guides together with meaningful anchor text.
- Share releases in relevant engineering communities only where self-promotion is allowed; disclose that you maintain the project.
- Invite real users to report issues and contribute tested improvements.
- Keep the project updated and remove obsolete instructions.
- Never buy links, stuff keywords, generate doorway pages, fake reviews, or claim guaranteed Google ranking.
